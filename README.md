# To-freedom
freedom and Technological Exploration

##项目简介

本仓库是我个人技术探索与成长的记录，旨在通过代码与实践，探索技术带来的自由与可能性。
内容涵盖编程学习、自动化脚本、数据处理工具等各类项目。

##仓库结构

-"scripts/": 实用脚本工具
-"project/": 完整项目代码
-"notes/": 学习笔记与心得

##使用说明

1.克隆仓库
"bash
git clone https://github.com/EF1016/To-freedom.git
"

2.进入项目仓库
"bash
cd To-freedom
"
